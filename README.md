# 질문 받기 연습실 · 사이트 올리는 방법

이 폴더에는 '질문 받기 연습실'을 자기 주소로 여는 데 필요한 파일이 모두 들어 있습니다. 데이터베이스는 없습니다. 파일을 올리기만 하면 됩니다. AI 기능은 원할 때만 따로 켭니다(아래 'AI 기능 켜기').

## 들어 있는 파일

| 파일 | 하는 일 |
| --- | --- |
| `index.html` | 화면 전체 |
| `qp-content.js` | 장면과 자료 내용 (편집표와 같은 내용) |
| `site-config.js` | 운영 이름, 문의처, Claude 판 주소, AI 중계 서버 주소. **처음에는 이 파일만 고치면 됩니다** |
| `favicon.svg` | 브라우저 탭에 보이는 작은 아이콘 |
| `og-image.png` | 카카오톡 등에 링크를 보낼 때 보이는 미리보기 그림 |
| `worker.js` | AI 중계 서버 코드. Cloudflare에 붙여 넣는 용도이고, GitHub에 함께 올라가도 괜찮습니다 (비밀 정보 없음) |
| `LICENSE` | 프로그램 코드의 라이선스 (MIT) |
| `LICENSE-CONTENT.md` | 내용의 라이선스 (CC BY-SA 4.0)와 출처 표시 방법 |
| `README.md` | 지금 읽고 계신 안내 |

## GitHub Pages로 올리기 (무료, 30분 안팎)

GitHub Pages는 GitHub Free 계정의 **공개(Public) 저장소**에서 무료로 쓸 수 있습니다. 공개 저장소이므로 내용이 누구에게나 보입니다. 오픈소스로 함께 고쳐 가려는 방향과 맞습니다.

1. github.com에서 계정을 만듭니다. 운영을 맡을 사람이나 모임 이름으로 만드는 것이 좋습니다.
2. 오른쪽 위 **+** → **New repository**를 누릅니다. 이름을 정하고(예: `qna-practice`) **Public**을 고른 뒤 **Create repository**를 누릅니다.
3. 새 저장소 화면에서 **uploading an existing file**을 누릅니다.
4. 압축을 푼 폴더를 열고, **폴더 안의 파일을 모두 선택해** 끌어다 놓습니다. 폴더째 올리면 사이트가 열리지 않습니다. 그다음 **Commit changes**를 누릅니다.
5. 저장소의 **Settings** → 왼쪽 **Pages**로 갑니다.
6. **Build and deployment**의 **Source**에서 **Deploy from a branch**를 고릅니다. 브랜치는 **main**, 폴더는 **/(root)**를 고르고 **Save**를 누릅니다.
7. 잠시 뒤 같은 화면 위쪽에 사이트 주소가 나옵니다. 보통 `https://계정이름.github.io/저장소이름/` 모양입니다.

## 처음 한 번 고칠 것: `site-config.js`

저장소에서 `site-config.js`를 누르고 연필 모양(수정)을 누른 뒤, 따옴표 안의 글자만 바꾸고 **Commit changes**를 누릅니다.

- `operator`: 운영하는 사람이나 모임 이름. 화면 맨 아래에 '운영: …'으로 나옵니다.
- `contact`: 문의처. 비워 두면 나오지 않습니다. 개인 메일보다 운영용 메일을 따로 만드는 것을 권합니다.
- `claudeUrl`: AI 기능이 있는 Claude 판 주소. 이 사이트에서 AI를 쓸 수 없을 때 안내 링크로 나옵니다.
- `aiEndpoint`: AI 중계 서버 주소. 비워 두면 이 사이트에서는 AI 기능이 꺼져 있습니다. 아래 'AI 기능 켜기'를 마친 뒤에 넣습니다.

**API 키는 절대 이 파일에 넣지 마세요.** 이 파일은 누구나 볼 수 있습니다. 실수로 넣으면 사이트 맨 위에 빨간 경고가 뜹니다. 그때는 바로 지우고 Claude 콘솔에서 그 키를 삭제하세요.

## AI 기능 켜기 (선택)

'직접 대답 연습'과 '대화 준비'의 AI를 이 사이트에서도 쓰려면, Claude API 계정과 작은 중계 서버(Cloudflare Worker, 무료)가 필요합니다. **AI 비용은 운영자의 Claude API 계정에서 나갑니다.** 중계 서버는 API 키를 숨겨 두고, 이 사이트에서 온 요청만 받아 Claude에 전달합니다.

### 1. Claude 콘솔: 충전, 한도, 키 (15분)

1. platform.claude.com에 가입합니다. claude.ai 구독과는 별개의 계정·결제입니다.
2. **Billing** 화면에서 **Buy credits**로 작은 금액만 충전합니다. 미리 충전한 금액을 다 쓰면 AI가 멈출 뿐 그 이상은 나가지 않습니다.
3. 같은 화면의 자동 충전(**auto-reload**)은 켜지 않습니다. 켜져 있다면 **Manage auto-reload** → **Turn off**.
4. 같은 화면 **Spend limits**에서 **Set limit**을 눌러 월 한도를 작게 정해 둡니다.
5. **API Keys**에서 새 키를 만들고 복사해 둡니다. 키는 만들 때 한 번만 보입니다. 메모장 등에 잠시 붙여 두고, 6단계가 끝나면 지웁니다.

충전한 크레딧은 산 날로부터 1년 뒤 사라지고 환불되지 않습니다. 처음에는 작게 시작하세요.

### 2. Cloudflare: 중계 서버 만들기 (15분)

1. cloudflare.com에서 무료 계정을 만들고 메일 인증을 합니다.
2. 대시보드 왼쪽 **Workers & Pages** → **Create**(또는 **Create application**)를 누릅니다.
3. **Hello World**로 시작하는 Worker를 고르고, 이름을 정한 뒤(예: `qp-ai`) **Deploy**를 누릅니다.
4. **Edit code**를 누르고, 왼쪽 코드 창의 내용을 모두 지운 뒤 `worker.js`의 내용 전체를 붙여 넣고 **Deploy**를 누릅니다.
5. Worker 화면의 **Settings** → **Variables and Secrets** → **Add**를 누릅니다. Type은 **Secret**, 이름은 `ANTHROPIC_API_KEY`, 값에는 1단계에서 복사한 키를 넣고 **Deploy**를 누릅니다.
6. Worker 주소(`https://qp-ai.계정이름.workers.dev` 모양)를 브라우저 주소창에 넣어 엽니다. "API 키: 넣음"이 보이면 됩니다.

### 3. 사이트에 연결 (5분)

1. GitHub 저장소에서 `site-config.js`를 열고 연필 모양을 누릅니다.
2. `aiEndpoint: ""`의 따옴표 안에 Worker 주소를 넣습니다. 예: `aiEndpoint: "https://qp-ai.계정이름.workers.dev"`
3. **Commit changes**를 누르고 1~2분 뒤 사이트를 새로 고칩니다. '직접 대답 연습'에서 대답을 보내 AI가 답하면 끝입니다.

### 끄기, 바꾸기

- **끄기**: `site-config.js`의 `aiEndpoint`를 `""`로 비우면 됩니다. 급할 때는 Claude 콘솔에서 키를 삭제하면 바로 멈춥니다.
- **한도에 닿으면**: 사이트에는 "AI 사용량이 정해 둔 한도에 닿았습니다"가 뜨고, 그 대화는 혼자 연습하는 방식으로 이어집니다. 다시 쓰려면 충전하거나 한도를 올립니다.
- **사이트 주소가 바뀌면**(자기 도메인 등): `worker.js` 맨 위 `ALLOWED_ORIGINS`의 주소를 새 주소로 바꿔 다시 Deploy합니다. 주소는 `https://`부터 도메인까지만 적습니다(뒤의 `/hun/` 같은 경로는 빼기).
- **모델**: 기본은 가장 저렴한 Claude Haiku 5.5입니다. 돌아보기와 준비 카드를 더 꼼꼼하게 하려면 `worker.js`의 `MODEL_DEEP`을 `"claude-sonnet-5-5"`로 바꿉니다. 그 부분의 비용은 약 20배가 됩니다.
- **횟수 제한**: 한 접속 주소에서 한 시간에 120번까지 받습니다(`PER_HOUR`). 교회 와이파이처럼 여러 사람이 한 주소를 쓰면 함께 셉니다.

### 미리 알아 둘 것

- 중계 서버 주소는 `site-config.js`에 있어 누구나 볼 수 있습니다. 중계 서버는 이 사이트에서 온 요청만 받고 횟수·길이를 제한하지만, 마음먹고 흉내 내는 요청까지 완전히 막지는 못합니다. 그래서 충전 금액과 월 한도를 작게 두는 것이 가장 확실한 안전장치입니다.
- AI를 켜면 쓴 글이 답을 만들기 위해 Claude(Anthropic의 AI)로 보내집니다. 사이트 맨 아래 안내도 그에 맞게 바뀝니다. 중계 서버는 글을 저장하지 않습니다.

## 우리 교단·교회 판 만들기

이 연습실은 누구나 복사해서 자기 판으로 운영할 수 있게 공개되어 있습니다(아래 '라이선스'). 자기 판을 만들면 자료 목록을 교단 지침에 맞게 고를 수 있고, AI 비용도 그 교단·교회의 계정에서 냅니다.

1. **복사하기**: GitHub에서 이 저장소를 열고 **Use this template** → **Create a new repository**를 누릅니다. 이 버튼이 없으면 **Fork**를 누릅니다.
2. **사이트 열기**: 위 'GitHub Pages로 올리기'의 5~7단계와 같습니다.
3. **설정 바꾸기**: `site-config.js`에서 `operator`와 `contact`를 자기 것으로 바꿉니다. 처음에는 `aiEndpoint`를 `""`로 비워 AI를 꺼 둡니다.
4. **AI를 쓰려면**: 위 'AI 기능 켜기'를 자기 Claude 콘솔 계정과 자기 Cloudflare 계정으로 따라 합니다. 이때 `worker.js` 맨 위 `ALLOWED_ORIGINS`를 **자기 사이트 주소**로 바꿔야 합니다. 그다음 `aiEndpoint`에 자기 Worker 주소를 넣습니다.
5. **자료 고르기**: `qp-content.js`의 자료 목록(RES)에서 교단 지침에 맞지 않는 자료는 빼고, 필요한 자료는 같은 모양으로 더합니다. 머리말에 편집 규칙이 있습니다.
6. **출처 남기기**: 화면 맨 아래 '이용 안내'의 저작권 단락은 지우지 말고 남겨 둡니다. 내용을 고쳤다면 `LICENSE-CONTENT.md`의 예시처럼 고쳤다는 사실을 적고, 고친 판도 같은 라이선스(CC BY-SA 4.0)로 공개합니다.

`aiEndpoint`나 `ALLOWED_ORIGINS`를 바꾸지 않고 두면, 원래 운영자의 중계 서버가 다른 주소에서 온 요청을 거절합니다. 그래서 비용이 엉뚱한 곳으로 가지 않고, 화면에는 "AI 연결에 문제가 생겼습니다"라는 안내만 나옵니다.

**원래 운영자가 한 번 해 둘 것**: 저장소 **Settings** → **General**에서 **Template repository**를 체크하면, 다른 교회가 1단계의 **Use this template** 버튼으로 바로 복사할 수 있습니다.

## 내용을 고칠 때

1. 편집표에서 자료나 장면을 고칩니다.
2. Claude에게 "편집표 내용을 연습실에 반영해 줘"라고 요청해 새 `qp-content.js`(필요하면 `index.html`)를 받습니다.
3. 저장소에서 **Add file** → **Upload files**로 같은 이름의 파일을 올려 덮어쓰고 **Commit changes**를 누릅니다. 1~2분 뒤 사이트에 반영됩니다. `site-config.js`를 새로 받아 덮어썼다면 `aiEndpoint` 등 고쳐 둔 값을 다시 넣었는지 확인하세요.

## 링크 미리보기 그림 켜기 (선택)

카카오톡 등에서 그림 미리보기가 나오려면 사이트 주소가 `index.html` 안에 들어가야 합니다. 주소가 정해지면 Claude에게 주소를 알려 주고 `index.html`을 다시 받아 올리면 됩니다. 제목과 설명 미리보기는 그림 없이도 나옵니다.

## 자기 주소(도메인) 쓰기 (선택)

도메인 업체에서 주소를 산 뒤, 저장소 **Settings** → **Pages** → **Custom domain**에 넣습니다. 업체 쪽 설정은 GitHub의 안내를 따르세요. 비용은 주소 종류에 따라 다르지만 보통 해마다 몇만 원 안쪽입니다. AI를 켜 두었다면 `worker.js`의 `ALLOWED_ORIGINS`도 바꿔야 합니다.

## 알아 둘 것

- AI를 켜지 않으면 이 사이트는 아무것도 수집하지 않습니다. 글자 크기와 '우리 교회 목록'만 쓰는 사람의 기기(브라우저)에 저장됩니다.
- 장면 연습, 상태 읽기, 같은 핵심 다른 언어, 선생님의 마음과 교회의 자리, 자료 길잡이, 6주 과정 안내는 AI 없이 모두 작동합니다.
- AI 기능(직접 대답 연습, 대화 준비)은 `aiEndpoint`를 넣었을 때만 작동합니다. 비워 두면 혼자 연습하는 방식과 Claude 판 안내가 나옵니다.
- 감수 전 체험판입니다. 공개 범위를 넓히기 전에 상담·이단 상담 전문가의 검토를 먼저 받기를 권합니다.
