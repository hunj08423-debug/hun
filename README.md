# 질문 받기 연습실 · 사이트 올리는 방법

이 폴더에는 '질문 받기 연습실'을 자기 주소로 여는 데 필요한 파일이 모두 들어 있습니다. 서버나 데이터베이스는 없습니다. 파일을 올리기만 하면 됩니다.

## 들어 있는 파일

| 파일 | 하는 일 |
| --- | --- |
| `index.html` | 화면 전체 |
| `qp-content.js` | 장면과 자료 내용 (편집표와 같은 내용) |
| `site-config.js` | 운영 이름, 문의처, Claude 판 주소. **처음에는 이 파일만 고치면 됩니다** |
| `favicon.svg` | 브라우저 탭에 보이는 작은 아이콘 |
| `og-image.png` | 카카오톡 등에 링크를 보낼 때 보이는 미리보기 그림 |
| `README.md` | 지금 읽고 계신 안내 |

## GitHub Pages로 올리기 (무료, 30분 안팎)

GitHub Pages는 GitHub Free 계정의 **공개(Public) 저장소**에서 무료로 쓸 수 있습니다. 공개 저장소이므로 내용이 누구에게나 보입니다. 오픈소스로 함께 고쳐 가려는 방향과 맞습니다.

1. github.com에서 계정을 만듭니다. 운영을 맡을 사람이나 모임 이름으로 만드는 것이 좋습니다.
2. 오른쪽 위 **+** → **New repository**를 누릅니다. 이름을 정하고(예: `qna-practice`) **Public**을 고른 뒤 **Create repository**를 누릅니다.
3. 새 저장소 화면에서 **uploading an existing file**을 누릅니다.
4. 압축을 푼 폴더를 열고, **폴더 안의 파일 6개를 모두 선택해** 끌어다 놓습니다. 폴더째 올리면 사이트가 열리지 않습니다. 그다음 **Commit changes**를 누릅니다.
5. 저장소의 **Settings** → 왼쪽 **Pages**로 갑니다.
6. **Build and deployment**의 **Source**에서 **Deploy from a branch**를 고릅니다. 브랜치는 **main**, 폴더는 **/(root)**를 고르고 **Save**를 누릅니다.
7. 잠시 뒤 같은 화면 위쪽에 사이트 주소가 나옵니다. 보통 `https://계정이름.github.io/저장소이름/` 모양입니다.

## 처음 한 번 고칠 것: `site-config.js`

저장소에서 `site-config.js`를 누르고 연필 모양(수정)을 누른 뒤, 따옴표 안의 글자만 바꾸고 **Commit changes**를 누릅니다.

- `operator`: 운영하는 사람이나 모임 이름. 화면 맨 아래에 '운영: …'으로 나옵니다.
- `contact`: 문의처. 비워 두면 나오지 않습니다. 개인 메일보다 운영용 메일을 따로 만드는 것을 권합니다.
- `claudeUrl`: AI 기능이 있는 Claude 판 주소. 이 사이트에서는 AI 기능이 작동하지 않아서, AI 연습을 원하는 분께 이 주소를 안내합니다.

## 내용을 고칠 때

1. 편집표에서 자료나 장면을 고칩니다.
2. Claude에게 "편집표 내용을 연습실에 반영해 줘"라고 요청해 새 `qp-content.js`(필요하면 `index.html`)를 받습니다.
3. 저장소에서 **Add file** → **Upload files**로 같은 이름의 파일을 올려 덮어쓰고 **Commit changes**를 누릅니다. 1~2분 뒤 사이트에 반영됩니다.

## 링크 미리보기 그림 켜기 (선택)

카카오톡 등에서 그림 미리보기가 나오려면 사이트 주소가 `index.html` 안에 들어가야 합니다. 주소가 정해지면 Claude에게 주소를 알려 주고 `index.html`을 다시 받아 올리면 됩니다. 제목과 설명 미리보기는 그림 없이도 나옵니다.

## 자기 주소(도메인) 쓰기 (선택)

도메인 업체에서 주소를 산 뒤, 저장소 **Settings** → **Pages** → **Custom domain**에 넣습니다. 업체 쪽 설정은 GitHub의 안내를 따르세요. 비용은 주소 종류에 따라 다르지만 보통 해마다 몇만 원 안쪽입니다.

## 알아 둘 것

- 이 사이트는 아무것도 수집하지 않습니다. 글자 크기와 '우리 교회 목록'만 쓰는 사람의 기기(브라우저)에 저장됩니다.
- 장면 연습, 상태 읽기, 같은 핵심 다른 언어, 선생님의 마음과 교회의 자리, 자료 길잡이, 6주 과정 안내는 모두 작동합니다.
- AI 기능(직접 대답 연습, 대화 준비)은 이 사이트에서 작동하지 않습니다. 대신 혼자 연습하는 방식과 Claude 판 안내가 나옵니다.
- 감수 전 체험판입니다. 공개 범위를 넓히기 전에 상담·이단 상담 전문가의 검토를 먼저 받기를 권합니다.
